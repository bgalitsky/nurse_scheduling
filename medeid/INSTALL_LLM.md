# Установка локальной языковой модели для medeid 2.0

Модель работает **на компьютере или сервере учреждения**. Текст медицинских документов не передаётся во внешние сервисы. medeid откажется работать, если адрес сервера модели находится вне локальной сети.

Есть два способа запуска: **Ollama** (проще, рекомендуется) или **llama.cpp** (одна программа без установки, удобно в закрытом контуре).

---

## 1. Какое нужно железо

| Модель | Файл | Память (ОЗУ или видеопамять) | Скорость |
|---|---|---|---|
| `qwen3:8b` (по умолчанию) | ~5 ГБ | от 8 ГБ | на видеокарте 8 ГБ+ — секунды на фрагмент; только на процессоре — до минуты на фрагмент |
| `qwen3:14b` | ~9 ГБ | от 12–16 ГБ | точнее, медленнее |
| T-pro 2.0 (русскоязычная, 32B) | ~20 ГБ (Q4_K_M) | от 24 ГБ | лучше понимает русский текст, нужен сервер с GPU |

Документ делится на фрагменты по 2 500 символов. Документ вроде `test1.docx` (58 тыс. символов) — это около 20 запросов к модели. Повторный запуск тех же файлов берёт ответы из кэша и проходит за секунды.

## 2. Вариант А: Ollama

### 2.1. Установка

**Linux:**
```bash
curl -fsSL https://ollama.com/install.sh | sh
```
Ollama устанавливается как системная служба.

**Windows / macOS:** скачайте установщик на https://ollama.com/download и установите.

По умолчанию Ollama слушает только `127.0.0.1:11434`, и так и нужно. **Не задавайте** `OLLAMA_HOST=0.0.0.0`, если модель не должна быть доступна другим компьютерам. Если сервер модели всё же отдельный, откройте порт только для внутренней сети.

Проверка:
```bash
ollama --version
curl http://127.0.0.1:11434/api/version
```
Нужна свежая версия Ollama: medeid отключает «размышления» модели параметром `think: false` и задаёт формат ответа JSON-схемой.

### 2.2. Загрузка модели

```bash
ollama pull qwen3:8b
```

Русскоязычная альтернатива от Т-Технологий (основана на Qwen, нужен мощный сервер):
```bash
ollama pull hf.co/t-tech/T-pro-it-2.0-GGUF:Q4_K_M
```
В этом случае в конфигурации укажите `имя: hf.co/t-tech/T-pro-it-2.0-GGUF:Q4_K_M`.

### 2.3. Дайджест модели (обязательно)

Дайджест — это отпечаток файла модели. medeid сверяет его перед каждым запуском, чтобы обновлённая или подменённая модель не изменила результат незаметно.

```bash
python -m medeid check-model -c config.yaml
```
Если поле `модель.дайджест` пустое, команда покажет нужное значение. Вставьте его в `config.yaml` и запустите команду ещё раз. Она должна сообщить «дайджест совпадает» и вывести пробное извлечение:

```
сервер http://127.0.0.1:11434: доступен, адрес внутренний
модель qwen3:8b: дайджест совпадает (…)
пробное извлечение:
  фио_пациента       Тестова Мария Олеговна
  телефон            +7 900 000-00-00
  ...
```
Дайджест можно посмотреть и напрямую: `curl http://127.0.0.1:11434/api/tags` (поле `digest`).

> После `ollama pull` модель может обновиться, и тогда изменится её дайджест. medeid не запустится, пока вы не проверите новую версию и не обновите дайджест в конфигурации. Так и задумано.

### 2.4. Компьютер без интернета (закрытый контур)

1. На компьютере с интернетом установите Ollama и выполните `ollama pull qwen3:8b`.
2. Скопируйте каталог моделей:
   - Linux (служба): `/usr/share/ollama/.ollama/models`
   - Linux (пользователь), macOS: `~/.ollama/models`
   - Windows: `%USERPROFILE%\.ollama\models`
3. Установите Ollama на целевом компьютере. Для Linux возьмите офлайн-архив `ollama-linux-amd64` со страницы релизов https://github.com/ollama/ollama/releases, для Windows — установщик. Затем положите скопированный каталог моделей на то же место (или укажите путь в переменной `OLLAMA_MODELS`).
4. `ollama list` должна показать модель с тем же ID. Дальше выполните шаг 2.3.

## 3. Вариант Б: llama.cpp (OpenAI-совместимый сервер)

1. Скачайте готовую сборку `llama-server` для своей ОС: https://github.com/ggml-org/llama.cpp/releases
2. Скачайте файл модели в формате GGUF, например Qwen3-8B Q4_K_M или `t-tech/T-pro-it-2.0-GGUF` с Hugging Face, и перенесите его на сервер.
3. Запуск только на localhost:
   ```bash
   llama-server -m /models/model.gguf --host 127.0.0.1 --port 8080 -c 8192 --jinja
   ```
4. Конфигурация:
   ```yaml
   модель:
     движок: openai
     сервер: http://127.0.0.1:8080
     имя: model.gguf                 # имя, под которым сервер отдаёт модель (/v1/models)
     файл_модели: /models/model.gguf # medeid сам посчитает sha256 файла
     дайджест: ""                    # заполнить после check-model
   ```
   Первый подсчёт дайджеста большого файла занимает минуту-две. Результат сохраняется рядом с файлом (`model.gguf.sha256`).

Так же подключаются vLLM и LM Studio (движок `openai`).

## 4. Настройка medeid

```yaml
извлечение: модель+правила        # рекомендуется
модель:
  движок: ollama
  сервер: http://127.0.0.1:11434
  имя: qwen3:8b
  дайджест: "<из check-model>"
  seed: 42
  контекст: 8192
  размер_фрагмента: 2500
  таймаут_сек: 600
  кэш: /secure/medeid/llm_cache.sqlite
версия_инструмента: 2.0.0
```

- **`кэш` содержит персональные данные:** это ответы модели, то есть найденные ФИО и адреса. Храните его рядом с базой ключей, на защищённом томе. medeid создаёт файл с правами 0600 и откажется работать, если кэш лежит в каталоге входных файлов или результатов.
- Если кэш не указан, повторяемость зависит от того, отвечает ли модель одинаково. Это обычно так на том же компьютере и той же версии Ollama, но не гарантировано при смене видеокарты или версии. `verify` покажет, совпали ли результаты.
- `извлечение: модель` — фрагменты находит только модель. Даты и возраст всё равно разбираются правилами. Контроль остатков выполняется правилами в любом режиме: что они найдут после модели, попадает в `_на_проверку`.

## 5. Как модель встроена (и почему ей нельзя «доверять вслепую»)

1. Документ делится на фрагменты. Модель возвращает список найденных фрагментов с категориями в формате JSON по фиксированной схеме.
2. **Каждый фрагмент ищется в тексте дословно.** Если модель вернула то, чего в документе нет (выдумала или «исправила» падеж), фрагмент отбрасывается и учитывается в статистике манифеста. Так же отбрасывается всё, что модель выдала по указаниям, «спрятанным» внутри документа.
3. Короткие числа («№ 15») заменяются только после «№», а не везде, где встретилось 15 (например, в дозе).
4. Подпись поля в строке («Врач:», «Пациент:») важнее мнения модели о роли человека.
5. Заменяет фрагменты детерминированный код по режимам из конфигурации, как в 1.x.
6. В манифест записываются имя модели, дайджест, версия сервера, версия и sha256 промпта, seed, а также сколько было запросов, сколько ответов взято из кэша и сколько фрагментов отброшено.

## 6. Перед работой с реальными документами

Прогоните 20–30 реальных документов в режиме `модель+правила` и проверьте результат вручную, особенно свободный текст: анамнез, «со слов…». Если модель часто пропускает какой-то вид сведений, попробуйте модель крупнее (`qwen3:14b`, T-pro 2.0). Если пропуски повторяются, сообщите — я расширю правила.
