# medocr — локальное распознавание сканов перед обезличиванием

Сканы и страницы без нормального текстового слоя распознаются **на этом компьютере** с помощью Tesseract. Данные никуда не отправляются. Результат — обычные PDF с текстовым слоем, которые затем обрабатывает medeid.

```
сканы (PDF) ──medocr──▶ папка исходных документов (PDF с текстом) ──medeid──▶ результаты
```

## Что делает с каждой страницей

| Страница | Действие |
|---|---|
| Хороший текстовый слой, без картинок с текстом | копируется без изменений |
| Скан (текста нет) | распознаётся; поворот определяется автоматически |
| Текст + вклеенное изображение, в котором есть слова (направление, скриншот УЗИ с ФИО) | распознаётся целиком, чтобы текст из картинки попал в текстовый слой и был обезличен |
| Текстовый слой «иероглифами» | распознаётся как изображение |
| PDF с паролем или повреждённый | не обрабатывается, причина пишется в отчёт |

- Для каждой страницы записывается средняя **уверенность распознавания**. Страницы ниже порога (по умолчанию 70%) отмечаются в самом PDF. medeid отправляет такой документ в `_review` на ручную проверку (инструкция, п. 6.1).
- Имена выходных файлов — только латиница: «Выписка_скан.pdf» → `Vypiska_skan.pdf`. Соответствие имён хранится в `ocr_index.csv` в той же папке (это хранилище исходников).
- Временные изображения страниц создаются внутри папки результата (`.medocr_tmp`) и удаляются сразу после обработки.
- Документ, уже распознанный ранее (по контрольной сумме), повторно не распознаётся.

## Установка

### Windows

1. Python-библиотеки:
   ```powershell
   pip install pypdfium2 pypdf pillow
   ```
2. **Tesseract**: установщик сборки UB Mannheim — https://github.com/UB-Mannheim/tesseract/wiki
   При установке на шаге **Additional language data** отметьте **Russian**. «Math / equation detection» и «osd» обычно ставятся по умолчанию: osd нужен для автоповорота.
3. Проверка:
   ```powershell
   "C:\Program Files\Tesseract-OCR\tesseract.exe" --list-langs     # в списке должны быть rus, eng, osd
   ```
   Если Tesseract не добавлен в PATH, укажите путь в `ocr.yaml` (ниже) или параметром `--tesseract`.

### Linux

```bash
sudo apt install tesseract-ocr tesseract-ocr-rus tesseract-ocr-osd
pip install pypdfium2 pypdf pillow
```

### Компьютер без интернета

Скачайте установщик Tesseract на другом компьютере. Если нужны языковые файлы отдельно, они лежат в https://github.com/tesseract-ocr/tessdata_best (точнее) или https://github.com/tesseract-ocr/tessdata_fast (быстрее): файлы `rus.traineddata`, `eng.traineddata`, `osd.traineddata`. Перенесите их в папку `tessdata` Tesseract. Python-библиотеки переносятся набором wheel-файлов: `pip download pypdfium2 pypdf pillow -d wheels`, затем `pip install --no-index --find-links wheels pypdfium2 pypdf pillow`.

### Проверенный источник (инструкция, п. 4.3)

Программа считает контрольные суммы языковых файлов и пишет их в `ocr_report.json`. Чтобы запретить работу с подменёнными файлами, внесите утверждённые суммы в `ocr.yaml`:
```yaml
sha256_языков:
  rus: "<sha256 rus.traineddata>"
  eng: "<sha256 eng.traineddata>"
```

## Настройки (необязательно)

Файл `ocr.yaml` в папке настроек medeid (`python -m medeid settings where`):
```yaml
tesseract: C:\Program Files\Tesseract-OCR\tesseract.exe
языки: rus+eng
dpi: 300                  # качество рендеринга страницы для распознавания
порог_уверенности: 70     # %, ниже — ручная проверка
доля_изображения: 0.15    # изображение больше этой доли страницы → страница распознаётся целиком
мин_доля_проверки: 0.01   # изображения от этой доли проверяются на наличие текста
слов_в_изображении: 3     # столько слов в изображении → страница распознаётся целиком
```

## Запуск

В окне medeid (оператор): кнопка **«Распознать сканы (OCR)…»**. Выберите папку со сканами, результат попадёт в текущую папку исходных документов. В журнале окна показываются только номера и статусы, без имён файлов.

Из командной строки:
```bash
python -m medocr -i scans/ -o source/
python -m medeid run -i source/ -o results/
```

Скорость: около 1–2 секунд на страницу на обычном компьютере (300 dpi). Скан плохого качества может распознаваться дольше.

## Ограничения

- Рукописный текст Tesseract почти не распознаёт: такие страницы получат низкую уверенность и уйдут на ручную проверку.
- Изображения (печати, QR-коды, снимки) как таковые не классифицируются. Распознаётся только текст в них.
- Распознанная страница — это изображение плюс невидимый текст. В результат medeid попадает только текст.
